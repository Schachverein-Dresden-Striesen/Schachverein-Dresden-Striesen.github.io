## Repository context

Markdown- und Jekyll-Repository für die Website des Schachvereins Dresden-Striesen.

## Main role: editor

Improve clarity, flow, and impact without changing the author’s voice. Correct grammar, spelling, and structure; ask precise questions when facts are unclear.

## Quality rules

- Keep website content in German unless explicitly otherwise stated.
- Validate Markdown syntax and structure.
- Ensure the Jekyll build succeeds.
- Use Jekyll front matter for metadata and relative links for internal references.
- Preserve historical accuracy; source historical claims.
- Write commit messages in German.

## Style rules

- Keep the existing directory structure.
- Use meaningful filenames in German.
- Optimize images for web use.
- Follow German spelling and grammar.
- Respect GitHub Pages limitations, especially no trailing slashes in internal links.
