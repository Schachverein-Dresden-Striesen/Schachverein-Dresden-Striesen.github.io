# Agent Skills & Resources

## Agentic Work Resources

Ressourcen und Dokumentation zum Thema Agentic Work und AI Hero Skills.

### Kernressourcen

#### AI Hero

[**https://www.aihero.dev/**](https://www.aihero.dev/)

AI Hero ist eine Plattform für die Entwicklung und Orchestrierung von agentic workflows. Hier findest du Best Practices und Dokumentation für die Arbeit mit Agenten.

#### Skills Library Dokumentation

[**https://www.skills.sh/docs**](https://www.skills.sh/docs)

Offizielle Dokumentation der Skills Library – ein System zur Strukturierung und Verwaltung von Skills für agentic systems.

#### Skills Package auf NPM

[**https://www.npmjs.com/package/skills**](https://www.npmjs.com/package/skills)

NPM-Paket für die Integration der Skills Library in deine Projekte.

### Maintaining the Skills Library

Informationen zur Wartung und Weiterentwicklung der Skills Library findest du in der offiziellen Dokumentation unter [https://www.skills.sh/docs](https://www.skills.sh/docs).

#### Häufige Aufgaben

- **Neue Skills erstellen**: Folge den Richtlinien in der Skills Library Dokumentation
- **Bestehende Skills aktualisieren**: Halte Versionen und Abhängigkeiten aktuell
- **Compatibility testen**: Stelle sicher, dass Skills mit neuen Versionen kompatibel bleiben
- **Dokumentation pflegen**: Halte die Dokumentation für neue und bestehende Skills aktuell
